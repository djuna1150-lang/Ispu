# ISPU Overlay

A simple Android overlay demo: a draggable red bubble opens a compact black/red menu above other apps. ISPU +, ISPU -, and RESET ISPU adjust a demo number only; they do not change another app's air-quality readings.

## Build on GitHub
1. Upload the contents of this folder to a GitHub repository (including the hidden `.github` folder).
2. Open **Actions** and run **Build Android APK** (it also runs on pushes to main/master).
3. Download the `ispu-overlay-debug-apk` artifact from a successful run.

Requires Android 6.0+ for overlay permission. Grant the overlay permission in Android Settings, then tap **MULAI BUBBLE**. This is a demo and has not been tested on every device.
